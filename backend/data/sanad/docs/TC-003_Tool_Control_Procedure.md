# TC-003 Tool Control Procedure

## 1. Custody

Every controlled tool has one custodian at any time: a tool board, a store, or a named person. Custody changes only by a recorded issue, a signed handover or a recorded check-in. The custody record is the authority on where a tool is.

## 2. Issue and return

A tool is issued from the tool crib against a job card, with an expected return time. The person it is issued to holds custody until they return it or sign it over.

<!-- page 2 -->
## 3. Locating a tool

3.1 The first source is the custody record: who holds the tool and where it was issued to.

3.2 Bench cameras at the gates record sightings of tagged tools. A camera detection is a sighting. It shows that a tool was seen at a place at a time. It is not a custody change and it is not a confirmed handover: the tool may have been moved since.

3.3 A sighting is confirmed only by a person verifying the tool physically and by its identity label.

3.4 Handover. A tool passes from one custodian to another only when the releasing custodian and the receiving person both sign the handover. Until then the tool remains assigned to the releasing custodian, whatever a camera shows.

<!-- page 3 -->
## 4. Controlled handover request

Where a tool is needed at another gate while it is issued elsewhere, raise a controlled handover request through tool control. The request notifies the current custodian and asks them to hold the tool for transfer when their task allows. It does not move the tool and does not change custody.

The transfer is then: verify the tool at the bench; sign the handover; carry the tool to the requesting gate; record its arrival by checking it in on the gate's tool board.

## 5. Calibration

A calibrated tool carries a label with its calibration expiry. Check the label before use. A tool whose calibration has lapsed is not used and is returned to tool control.

## 6. Substitution

A tool named in a job card is not substituted unless the job card names the alternative. Where a named tool is missing, the task waits for it.
